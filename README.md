# immptl-compat

Rough compatibility patches for [Immersive Portals](https://modrinth.com/mod/immersive-portals-neoforge).
I don't advise relying on these, prefer waiting for fixes to be adopted by the original mod.

All credits go to the original authors.

## Current fixes:
- [ae2](https://github.com/AppliedEnergistics/Applied-Energistics-2): fix missing DimensionIntId for "ae2:spatial_storage" ([#54](https://github.com/iPortalTeam/ImmersivePortalsModForNeo/issues/54)).
- [mekanism](https://github.com/mekanism/Mekanism): fix hasPlayerTracking to additionally check ImmPtl's chunk tracker ([#63](https://github.com/iPortalTeam/ImmersivePortalsModForNeo/issues/63)).
